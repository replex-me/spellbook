# Ordered patch series

The order and aggregate byte hash of these patches are locked by `../upstream.json`. Later patches may extend tests or implementation introduced earlier, so apply the complete series cumulatively.

Each engine change must have a native regression test for the violated invariant: one Undo boundary, exact Undo/Redo, failure rollback, object identity, master/layout preservation, or save/reopen semantics. Case-specific slide numbers, object names, coordinates and corpus identifiers are not valid production conditions.

The current `undo-v18` r3 development candidate extends the cumulative series through table API inheritance, table text-cursor Undo, exact existing-master layout selection, observable mixed-script text formatting, native object creation/duplication, metric-driven text-layout invalidation, sparse-master-safe slide insertion and bounded object interactions in `0027`–`0036`. Patch `0036` also moves PPTX click-action serialization to one shared shape-export boundary so text, table, group, connector, media and ordinary drawing shapes preserve the same interaction contract across save and reopen. `sourcePatchSeriesReady` records clean-source build admission; `sourceCandidateReady` stays false until the integrated source-level native suites pass for this exact patch hash. Runtime promotion remains separate and requires the browser, OOXML, visual and PowerPoint gates described in the parent README.
